# 🌍 Travel Recommendation

Este projeto foi desenvolvido como **Projeto Final** do curso **JavaScript Programming Essentials**, oferecido pela **IBM** na plataforma **Coursera**.

A aplicação permite aos usuários pesquisar recomendações de viagens com base em categorias como praias, templos e países, exibindo informações e imagens de forma dinâmica.

## ✨ Funcionalidades

* Página inicial com apresentação do projeto
* Página **About Us**
* Página **Contact Us**
* Barra de pesquisa por palavras-chave
* Recomendações dinâmicas utilizando **Fetch API**
* Carregamento de dados a partir de um arquivo JSON
* Botão para limpar os resultados da pesquisa
* Interface responsiva

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* JSON
